ShopEase – Online Shopping Website



Project Introduction



ShopEase is an online shopping website that I created as part of my Full Stack Development internship. The main purpose of this project is to build a simple shopping platform where users can view products and place orders easily.



What I Built



I created a responsive website with a clean layout and easy navigation. Users can explore different products, search for products, select categories, and manage their shopping cart.



The checkout feature allows users to enter their details and place an order. The order information is stored in an SQLite database using a Python Flask backend.



Key Features



Simple and user-friendly website design.



Product display with different categories.



Product search and category filters.



Add to cart and remove from cart.



Update product quantity.



Automatic calculation of the cart total.



Checkout form to place orders.



Database integration for storing orders.



Stock management after successful checkout.



Responsive design for mobile and desktop screens.

Running the Project



First, install the required dependencies:



pip install -r requirements.txt



Then run the application:



python app.py



Open the following address in your browser:



http://127.0.0.1:5000/



Project Testing



I tested the main features, including product loading, searching, cart management, and checkout. I also checked the SQLite database and confirmed that all 12 sample products and the test order were saved successfully.



What I Learned



While developing ShopEase, I learned how to connect a frontend application with a Python backend, work with an SQLite database, create API endpoints, and handle customer orders.
