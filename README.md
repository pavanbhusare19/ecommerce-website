# 🛍️ ShopEase – Online Shopping Website

**A Modern & Responsive E-Commerce Web Application**

---

## 🌟 Project Overview

ShopEase is a simple and user-friendly online shopping website developed as part of my Full Stack Development internship.

The project provides a smooth shopping experience where users can explore products, search by name, browse different categories, manage their shopping cart, and place orders through a checkout form.

## 💻 What I Developed

I built ShopEase with a clean interface, responsive design, and interactive shopping features. I also integrated a Python Flask backend with an SQLite database to manage products, customer orders, and stock information.

## ✨ Key Features

- 🛒 **Product Browsing** – Explore a collection of 12 sample products.
- 🔍 **Product Search** – Find products easily by name.
- 🏷️ **Category Filtering** – Browse products by different categories.
- 🛍️ **Shopping Cart** – Add, remove, and manage products.
- ➕ **Quantity Management** – Increase or decrease product quantities.
- 💰 **Price Calculation** – Automatically calculate the cart total.
- 📦 **Order Placement** – Place orders using the checkout form.
- 🗄️ **Database Integration** – Store product and order information using SQLite.
- 📊 **Stock Management** – Automatically update product stock after successful orders.
- 📱 **Responsive Design** – Access the website on desktop and mobile devices.

## ⚙️ Technologies Used

## 🚀 How to Run the Project

**Step 1 – Install Dependencies**

```bash
pip install -r requirements.txt
```

**Step 2 – Start the Application**

```bash
python app.py
```

**Step 3 – Open in Browser**

```text
http://127.0.0.1:5000/
```
